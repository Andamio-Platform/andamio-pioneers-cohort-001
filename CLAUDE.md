## Repository Purpose

This is the documentation repository for **Andamio Pioneers Program Cohort #001** - a 10-week program for early adopters testing and providing feedback on Andamio V2.

## Repository Structure

- `README.md` - Program overview and weekly meeting schedule
- `agendas/` - Meeting agenda markdown files (named by date: `YYYY-MM-DD.md`)
- `andamio-v2-audit.pdf` - Andamio V2 security audit report

## Content Guidelines

Meeting agendas follow this format:
- Header: `## Andamio Pioneer Program Meeting Agenda`
- Blockquote with cohort and meeting number: `> Cohort #001, Meeting #XX (YYYY-MM-DD)`
- Numbered sections for agenda items
- Links section at the bottom with program resources
