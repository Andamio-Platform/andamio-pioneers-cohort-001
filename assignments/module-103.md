# Module 103 Assignment — Make a Commitment

In Andamio Pioneers, we have taken a first look at how to use Andamio.

The purpose of Andamio APIs is to help you build apps using the Andamio Protocol.

For this assignment, make a commitment about what you will do.

---

## The assignment

Decide what you will build with the **Andamio App Template**, then post your commitment in **Andamio Discord**.

A real commitment has four parts:

1. **What you'll build** — one or two sentences. Specific enough that someone reading it three weeks from now could check whether you did it.
2. **Which skill you'll start with** — pick one of the embedded skills you've learned about: `/getting-started`, `/auth-setup`, `/explore-api`, `/cost-estimator`, `/troubleshoot`, or another.
3. **A date** — when you intend to have something working, even if rough.
4. **A link to your fork** — so we can see what you started from.

## Post format

```
🛠️ Pioneer Commitment

Building: <what you're building, 1–2 sentences>
Starting skill: </skill-name>
By: <YYYY-MM-DD>
Fork: <link to your fork of andamio-app-template>
```

Optional but encouraged:

- A link to any issue or feature request you've filed against the App Template
- A question you'd like help with from the cohort

## Why this assignment

Forking and running the template proved the technical work. Building something proves the rest of it.

Public commitments compound. When you post in Discord, you give the cohort a way to ask "how's that going?" three weeks from now — and you give us signal about which skills, which APIs, and which workflows actually carry weight.

## What "done" looks like

- [ ] Your commitment is posted in Andamio Discord
- [ ] Your fork link is included
- [ ] You've named at least one skill you'll start with
- [ ] Your build target is specific enough to verify in plain English

**Submit:** paste a link to your Discord post in your assignment submission.
