## 4. If Time: Introducing andamio-dev

The developer experience layer for Andamio Protocol. This is how we want new developers to learn Andamio — and it's ready for Pioneers to try.

**What it is:** A Claude Code plugin with two modes:
- **Learning Mode** — 7-module interactive course ("Build on Andamio"). AI instructor delivers lessons, assessor evaluates assignments, credentials settle on-chain.
- **Operational Mode** — 10 skills for real work: `/auth-setup`, `/explore-api`, `/course-ops`, `/project-ops`, `/cost-estimator`, `/troubleshoot`, and more.

**How to try it:**
```
# In Claude Code
/install andamio-dev

# Start the course
/learn

# Or jump straight to operations
/start
```

**The course covers:**
| Module | What You Learn |
|--------|---------------|
| 100 | Contribution-centered learning, CLI setup, wallet funding |
| 200 | Access tokens, API keys, headless auth |
| 300 | Reading the API, navigating the spec, querying credentials |
| 400 | The TX state machine — build, sign, submit, register, wait |
| 500 | Courses end-to-end — create, publish modules, manage learners |
| 600 | Projects end-to-end — tasks, contributors, treasury |
| 700 | Build something real — integration, cost estimation, your own app |

**Live demo:** Walk through Module 100.1, show the instructor delivering a lesson, show an operational skill in action.

**Why this matters for Pioneers:** This is the same content you've been learning in sessions — now it lives in your terminal. Learn at your own pace, get assessed by the agent, earn the same credential.

Opens another round of "can I build that?" — now with the tooling in hand.
